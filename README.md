# ✅ TaskMaster - Pro ToDo Ap

## 📖 About The Project
A beautiful, feature-rich To-Do list application built with Flutter. Designed to help you organize your life with 
ease, featuring task categorization, priorities, and a sleek dark mode.

## ✨ Key Features

* **✨ Smart Onboarding: A smooth introduction to the app's features.** 
* **📝 Task Management: Create, edit, delete, and toggle tasks instantly.** 
* **🗂️ Categories: Organize tasks by Work, Personal, Shopping, Health, and more.** 
* **🔥 Priorities: Visual indicators for Low, Medium, and High priority tasks.** 
* **📅 Date & Time: Set specific due dates and times for every task.** 
* **🌗 Dark Mode: Fully supported system-wide dark mode toggle.** 
* **📜 History: View and restore completed tasks.** 
* **🎨 Modern UI: Built with Material 3 design principles.**

## 🛠️ Technologies Used

* **Framework** - Flutter.
* **Language** - Dart.
* **Icons** - Material Icons.
